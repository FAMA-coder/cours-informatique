# Informatique 10ème CG — CPIES Mali

Cours interactif (10 leçons, 12 activités) pour les élèves de 10ème année.

## Consulter en ligne

    https://fama-coder.github.io/cours-informatique/

## Contenu du dépôt

- `index.html` : le cours complet. HTML, CSS et JavaScript sont réunis dans un
  seul fichier, sans aucune dépendance externe. Le cours fonctionne donc aussi
  hors ligne une fois la page enregistrée sur le téléphone.

## Adapter le cours

Tout le contenu pédagogique est dans la constante `curriculum` en haut du
`<script>` de `index.html`. Pour ajouter une leçon, dupliquez un bloc existant
et modifiez son `id`, `ua`, `title`, `situation`, `activities` et `course` : elle
apparaîtra automatiquement dans le menu.

## Mise à jour

Remplacer `index.html`, puis valider le commit. La republication sur GitHub
Pages se fait seule en 1 à 2 minutes.
